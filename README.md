## 🚀 Featured Projects

### 🏫 MCA Connect → SCIS Connect — Student Platform

**Live:** [scisconnect.up.railway.app](https://scisconnect.up.railway.app/) · **Team:** [MCA Connect](https://github.com/MCA-connect) · **Public code references:** [MCA Connect frontend](https://github.com/MCA-connect/MCA-Connect-frontend) · [MCA Connect backend](https://github.com/MCA-connect/MCA-Connect-backend)

MCA Connect was the original platform built collaboratively by the Connect team. We later integrated and evolved it into **SCIS Connect**, a student platform for the School of Computer and Information Sciences at the **University of Hyderabad**.

The platform has been used by SCIS students since **June 2026** and is designed to support large-scale adoption across the student community. It brings together:

- role-based access control and secure authentication
- MCQ, SQL, coding and file-upload assessments
- timed tests, autosave, recovery and results workflows
- real-time activity, leaderboards and user interactions
- frontend, backend and a dedicated query-server layer
- Docker, Nginx and cloud deployment workflows

This is a team-built, actively used product rather than a standalone demo. The Connect team continues to maintain and improve the platform for the SCIS student community.

### 🌱 GREENScore Hyderabad — Sustainability Scoring MVP

**Project:** [Green-score](https://github.com/vijaysingh60/Green-score)

A hackathon MVP for assessing building sustainability in Hyderabad. It combines rule-based preliminary scoring, an advisory ML score, recommendations, a what-if simulator and human-admin verification before publishing a final score.

**Highlights:** Next.js · Express · MongoDB · FastAPI · scikit-learn · Leaflet · Recharts

### 🤖 PromoPilot — AI/ML Promotion & Inventory Planner

**Project:** [Product Promotion](https://github.com/vijaysingh60/Product_Promotion)

An explainable promotion-planning system that recommends **what to promote, for which customer segment, in which city and at what discount** while balancing incremental profit, pricing rules, inventory safety and marketing budget.

- deterministic decision engine with typed response, demand and inventory model seams
- earlier XGBoost uplift-model service and synthetic retail dataset for ML experimentation
- city-level stock protection, safety-stock limits and stockout-risk considerations
- budget allocation based on incremental profit per promotion cost
- clearance recommendations, alternatives and customer-segment fatigue handling
- interactive Next.js dashboard, simulator, analytics and natural-language assistant

**Highlights:** TypeScript · Next.js · XGBoost · Python · Synthetic Data · Decision Systems · Analytics

### 🕸️ Apache Giraph Graph Algorithms

**Project:** [APACHE-GIRAPH-PROJECT-](https://github.com/25mcmc34-kumarshivam/APACHE-GIRAPH-PROJECT-)

An experiment-driven distributed graph-processing project built on Ubuntu, Hadoop and Apache Giraph. It includes reproducible datasets, measured outputs and implementations or evaluations of:

- PageRank, BFS and single-source shortest paths
- in-degree and out-degree analysis
- Graph Burning simulations with local Python verification
- HDFS/YARN workflows and multi-node experiment planning
